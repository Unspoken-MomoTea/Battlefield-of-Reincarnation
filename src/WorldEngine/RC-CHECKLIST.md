## 1. RC 冻结规则

从本清单建立起，世界推进进入 Release Candidate 测试阶段。

- 暂停 Phase 76 / Run Pipeline Decomposition 等大规模架构拆分。
- 测试阶段只允许修复明确复现的 BUG、兼容问题、UI 交互问题和测试门槛问题。
- 不为了“文件更小”“class 更多”继续机械拆分已经职责完整的类。
- 每次修复必须继续通过统一世界引擎 RC suite；修改源文件后必须保持生成交付物同步。
- 实机测试完成前，不把“自动化全绿”等同于“正式发布完成”。

### 关于 `tests/world-engine.cjs`

`tests/world-engine.cjs` 是早期约 2000 行的 legacy 单体测试，包含大量已经被后续分域测试替代的历史实现断言。它不是当前 RC 自动发现规则 `world-engine-*.cjs` 的一部分，不作为 RC 阻塞门槛。

当前 RC 以职责拆分后的 76 个 `world-engine-*.cjs` + 3 个固定集成为权威回归集；不要为了让 legacy 单体测试变绿而把已经完成的架构/UI/Prompt 设计倒退回旧实现。
