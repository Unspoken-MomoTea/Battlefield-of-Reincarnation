<生产制作协议>
生产制作:
  核心指令: 仅当{{user}}输入涉及明确制作行为时激活
  判定底层: 所有未另行规定的检定规则均直接继承《行为判定》
  专用规则: 本协议仅补充制作分类、配方、工坊、材料、产出与制作专属结果
  面板规则: 生产行为使用<CraftResult>作为专用结算面板，不额外重复输出普通<CheckResult>

  制作判定继承:
    - 制作行为如符合《行为判定》的优势/劣势条件，直接沿用对应2d100取高/低规则
    - 复杂工艺、材料缺陷、工坊条件等制作专属修正仅作为最终DC修正；通用环境修正沿用《行为判定》，不得重复计算

# 制作分类与门槛:
  1. 半成品制作 (材料 → 中间组件):
     - 特点: 必须掌握对应生产技艺；产物仅用于已知配方/图纸的后续制作，不具备独立使用效果，不作为独立商品产出；需要检定
  2. 成品制作 (材料/半成品 → 最终独立可用装备/药剂/道具):
     - 特点: 必须掌握对应生产技艺与【配方/图纸】；需要检定；成功后获得职业积累

# 技艺与配方:
  - 掌握生产技艺仅代表具备对应制作能力；成品必须拥有对应配方/图纸
  - 成品品质由配方决定，且不得高于对应生产技艺品质；技艺不足直接禁止制作
  - 半成品仅允许制作已掌握配方/图纸明确要求的中间组件，其材料、比例与产量不得自行设计
  - 制作数量由配方标准产量与实际材料决定；散装材料不得自行拆分为任意“材料份”
  - 研磨、切割、熔化、提炼等简单处理仅作为过程描述，不得单独结算、写入背包、提升品质或产生可交易产物
  - 行业最低工坊/工具属于制作前置条件，缺失时禁止制作，不得以提高DC代替

# 行业关联属性与工坊要求:
  - 锻造 (金属武器/重甲/机械零件): 力量修正 ｜ 需锻造台/熔炉
  - 炼金与制药 (药剂/毒素/爆炸物): 精神修正 ｜ 需药炉/炼金台
  - 烹饪 (恢复料理/短期增益食物): 体质修正 ｜ 需厨房/野炊营火
  - 裁缝与工艺 (布甲/皮甲/卷轴/首饰): 敏捷修正 ｜ 需缝纫台/精工工具

# 第二阶段: 制作检定
  逻辑与规则:
    1. 基础DC: 按《行为判定》的品质DC表读取
    2. 检定公式: d100 + 关联属性修正 + 工坊/技能加成 vs 最终DC
    3. 结果划分:
       - 💥精益求精 (骰值96-100 或 结果≥DC+50): 完美产出！批量产量+20%，单件获得额外专属词条或数值取上限
       - ✅制作成功 (结果≥DC): 正常产出，数值取该品质标准中值
       - ⚠️制作失败 (结果<DC 且 骰值>5): 制作未完成，损耗50%投入材料
       - 💀灾厄大失败 (骰值1-5 或 结果≤DC-50): 炸炉/断刃，100%投入材料损毁，并承受轻微物理/反噬伤害

  面板模板:
  <CraftResult>
    {制作检定}
    | 制作目标: [物品名] (品质: [F~SSS]) | 数量: [N] |
    | DC构成: 基础DC [X] + 复杂工艺修正 [+Y] - 工坊/工具加值 [-Z] = [最终DC] |
    | 制作检定: d100([骰值]) + 属性修正[±X] + 技能/特性加成[±Y] = [总值] vs DC [最终DC] |
    | 判定评级: [💥精益求精 / ✅制作成功 / ⚠️制作失败 / 💀大失败] |
    | 资源与时间实扣: EP -[X] | 消耗时间: [实际经过时间] |
  </CraftResult>
  叙事指导: (白描淬火瞬间、药液凝固、刻画符文时的光华流动与张力)
