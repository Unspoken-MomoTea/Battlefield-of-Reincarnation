# 世界推进开发文档

这里是“世界推进 / 世界引擎”的专属重构文档目录。运行时代码仍位于 `script/world-engine-src/`，最终仍通过 `tools/build-world-engine.py` 构建为单文件 `script/世界推进系统.js`。

## 当前目标

1. 把 `SamsaraWorldEngine` 从“承载所有职责的巨型类”收缩为协调器。
2. 业务能力按领域类拆分：请求构建、提示词、事件、世界人物、历史、写回、UI。
3. 所有实际发送给 AI 的可变文字都进入统一提示词目录，并在“提示词预设”中显示、编辑、保存、导入与导出。
4. 程序 Schema、字段校验、状态机和安全约束仍属于代码，不伪装成可编辑提示词。
5. 正式人物资料继续由状态栏负责；世界推进只维护 `世界.后台.人物`。
