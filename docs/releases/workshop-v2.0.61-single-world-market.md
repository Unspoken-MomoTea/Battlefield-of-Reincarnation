# 创意工坊 v2.0.61 · 单一世界空间集市交易解锁

## 玩家更新说明
- **单一世界：无需返回主神空间。** 当前存档设为 `设置.单一世界=true`，且 `系统状态.是否战斗中` 不为 true 时，可直接使用空间集市上架、购买、发布自由订单、提交报价、成交和领取。
- **普通多世界：规则不变。** 仍须返回主神空间，并且处于非战斗状态才可交易。
- **战斗中禁止交易。** 主神空间及单一世界均不能在战斗状态转移市场资产。
- **浏览始终可用。** 在任务世界仍可查看市场报价、拍卖商品和自由订单。
- **一致的提示与按钮状态。** 上架编辑器、自由订单编辑器和市场服务统一使用同一判定；面板显示是否可交易与单一世界区域标签。

## 技术说明
- 把是否可交易统一在 `canTradeInMarket(statData)`；与状态栏商城一致：
  `!是否战斗中 && (是否在主神空间 || 设置.单一世界)`。
- 保留 `inventory.inHub` 表示真实地点，新增 `inventory.canTrade` 避免将“单一世界”错误展示成“主神空间”。
- 原有存档 ID 绑定、MVU 托管、未确认领取、退款去重、原存档守卫不变。
- 回归覆盖单一世界上架／自由订单托管／退款领取、普通世界阻止交易、战斗中拒绝交易。
- 客户端版本：2.0.61；Worker 代码未变，仍为 0.13.22。
- 世界推进、状态栏、辅助计算正式通道不随本次升级。
