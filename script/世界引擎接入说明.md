# 世界引擎接入

## 运行依赖

`世界推进系统.js` 作为独立酒馆脚本加载，并与状态栏、`ZOD脚本.js`、`辅助计算脚本.js`、结算任务美化，以及世界书 `[variables]当前变量` / `[mvu_update]变量更新规则` 协同工作。

世界推进唯一开发源码位于 `src/WorldEngine/`。酒馆实际加载的 `script/世界推进系统.js` 是构建生成的单文件交付物，不直接作为业务源码维护。

## 开关与 API

终端「世界推进」总开关是独立世界引擎的用户开关。独立脚本未加载时不能启用；关闭时继续使用原世界面板和旧正文/MVU 世界推演逻辑。

世界推进支持两种互斥模型来源：

- 默认复用主神终端「额外模型配置」。
- 启用「世界推进专属 API」后，只使用世界推进自己的地址、Key、模型与预设，不偷偷回退到主神终端 API。

当前选定通道未就绪时自动推进暂停，并让正文/MVU 回到旧世界推演路径。

## 自动推进与重试

自动推进按正文轮次计数，战斗中不计轮；同一楼层普通重复通知不会重复推进。变量被“重新处理”并回滚当前到期楼层处理锚点时，可以重新补跑该轮。

主推进的超时、HTTP/网络错误、空回、解析失败与可纠正的业务验收失败进入自动重试；玩家主动取消、聊天/楼层上下文切换、时间锚点变化、配置未就绪和写入安全错误不自动重试。配置 Fallback 模型时，主模型用尽本模型尝试次数后才切换备用模型。

## 开发与构建

修改 `src/WorldEngine/` 后执行：

```bash
python tools/build-world-engine.py
python tools/build-world-engine.py --check
node tests/world-engine-modules.cjs
node tests/run-world-engine-suite.cjs
```

构建器只按固定顺序拼接源码，不压缩、不重写、不注入业务文本。禁止恢复 `script/world-engine-src/` 或直接在生成文件承载新业务逻辑。

## 编辑与 Prompt

事件、世界人物活动、因果偏移与历史记忆的手动修正统一通过 `src/WorldEngine/` 的 Controller/Service 写回；正式人物档案仍由状态栏编辑模式负责。

所有实际发送给 AI 的静态指令必须登记 `WorldPromptRegistry`，并能在「提示词预设 → 全部实际提示词」查看和编辑。Schema、字段白名单、时间/引用校验以及动态诊断属于程序契约或运行数据，不属于可编辑 Prompt。
