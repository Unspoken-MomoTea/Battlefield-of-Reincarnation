# 创意工坊 2.0.65 · 空间集市手机端巨额空间币排版修复

## 修复内容
- 手机屏幕宽度不超过 650px 时，空间集市的四项摘要（空间币、区域、交易、待领货款）改为固定 **两列自适应网格**，不会因为一个长数字导致卡片互相挤压或随意换列。
- 摘要卡添加 `min-width:0`、`max-width:100%` 和盒模型约束，超长金额在卡片内自动换行，不撑开父级或挤到其他元素。
- 「浏览 / 出售 / 订单 / 我的拍卖」使用单独不允许压缩的导航行，四个按钮保留至少 44px 的触控高度。极窄屏幕可以横向滚动导航。
- 同时约束平板宽度下的摘要容器，保持移动端与桌面端各自正常布局。
- 不更改存档中的空间币实际值、不做资产上限和金额四舍五入。
- 增加手机端摘要宽度/折行与导航按钮的 UI CSS 契约回归。

## 版本
- CreativeWorkshop: **2.0.65**
- Cloudflare Worker: 0.13.23（后端没有更改）
