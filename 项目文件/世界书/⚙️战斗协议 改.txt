<战斗协议>
战斗:
  核心指令: 仅当存在明确敌对双方且进入交战状态时激活，其余探索/交互情境严禁触发

# 第一阶段: 战况总览
  逻辑与规则:
    1. 战斗类型: 切磋/竞技/压制/死斗/标准/防卫战/突围战 (决定战意阈值与叙事基调)
    2. 回合资源: 每单位每回合基础拥有: 主要行动×1、次要行动×1、移动×1
    3. 状态刷新: 依次结算上回合残留的 [控制判定 → 持续伤害(DoT) → 持续恢复(HoT) → 技能/形态冷却减少]
    4. 实体展示: 列出场上全员当前真实 HP/THP/EP、核心五维修正、生效中状态与载具/形态参数
    5. 频率: 每回合开始输出一次

  面板模板:
  <CombatResult>
    {战况总览}
    | 回合: [当前回合数] | 战斗类型: [战斗类型] | 战场环境: [地形/光照/距离/掩体] |
    | [友方/玩家单位 (生命位格)]: HP [当前/最大] $(若有THP: | THP [当前]) | EP [当前/最大] | 修正: 力[±X] 敏[±X] 体[±X] 精[±X] 魅[±X] |
    | 状态: [生效状态A(N回合), 状态B...] $(若驾驶载具: | 载具完整度: [X%] | 能源: [X%]) |
    | [敌方单位/群体#番号 (生命位格)]: HP [当前/最大] $(若有THP: | THP [当前]) | 数量: [N] | 修正: 力[±X] 敏[±X] 体[±X] 精[±X] 魅[±X] |
    | 状态: [生效状态A(N回合), 状态B...] |
  </CombatResult>
  叙事指导: (描写当前的对峙局势、环境氛围、角色的状态外貌，为本回合定调)

# 第二阶段: 行动顺位
  逻辑与规则:
    1. 先攻公式: 1d100 + 先攻DC
    2. 参战资格: 仅当前存活且具备行动资格的单位参与排序（被控制/失能/脱离战场的单位不参与）
    3. 排序铁律: 降序排列生成本回合唯一行动轴，本回合顺位锁定，不因中途控制/位移/伤亡而改变
    4. 频率: 每回合输出一次

  面板模板:
  <CombatResult>
    {行动顺位}
    | [单位A]: 1d100([骰值]) + 先攻DC[±X] $(若存在额外先攻加值: + ${其他修正}[±Y]) = [总值] |
    | [单位B]: 1d100([骰值]) + 先攻DC[±X] $(若存在额外先攻加值: + ${其他修正}[±Y]) = [总值] |
    | 行动轴锁定: [单位A] -> [单位B] -> [单位C] -> ... |
  </CombatResult>
  叙事指导: (描写双方的反应速度，谁先动了，谁慢了一拍，空气中紧绷的一触即发感)

# NPC战术决策层 (主要行动前强制执行)
  - 适用: 实际参战且有行动资格的敌对NPC；背景人群、中立单位与失能单位跳过
  - 行动前读取敌我 HP/THP/EP、状态、技能、装备、位置、数量与环境，结合性格、职业和任务确定目标
  - 目标从击杀、控制、削弱、保护、救援、占位、脱离中选择；精英及以上优先采取当前局势下最有效的方案，不得无理由重复普攻
  - 杀伤优先: 在符合自身目标、性格、阵营与能力限制的前提下，若存在可执行的击杀机会，优先选择能直接提高玩家死亡或失能风险的有效行动，不得为展示技能、强行联动或等待后续机会而主动放弃明确击杀机会
  - 存在明确且可执行的有效联动时，优先组合技能、装备、状态、环境或队友能力；若直接行动已足以完成当前目标，则无需强行联动
  - 只能调用已生成、已装备、未冷却、资源足够且目标可及的能力；局势变化时更新下一次行动方案，不得在已声明的主要行动结算过程中临时改行动
  - 战术决策仅用于选择本次行动，不消耗任何行动资源，不产生额外行动
  - 输出简短战术摘要，不泄露NPC完整内心
    <CombatResult>
      {NPC战术决策}
      | 战术单位: [NPC/群体名] | 当前目标: [击杀/控制/削弱/保护/救援/脱离/占位] |
      | 局势判断: [关键HP/THP/EP、状态、位置、数量或环境信息] |
      | 战术方案: [本次行动及目标] | 能力联动: [技能/装备/状态/队友/环境之间的具体联动 / 无] |
    </CombatResult>

# 第三阶段: 主要行动 (核心循环)
  逻辑与规则:
     1. 消耗: 消耗行动方的 1[主要行动] (用于攻击、施法、重型战术技能或主炮齐射)
     2. NPC执行顺序: 敌对NPC必须先完成<NPC战术决策层>，再声明并执行主要行动；玩家与非敌对单位可直接声明行动
     3. 属性与动作合法性:
        - 默认属性关联: 重型武器:力量修正 | 远程武器:敏捷修正 | 法杖:精神修正 | 圣物:魅力修正
        - 动作物理合法性: 单手挥舞超重双手武器、双手持武器徒手结印等判负；若 使用者生命层级 ≥ 武器品质，默认具备驾驭能力豁免常规限制；否则必须判定动作失败或给予破绽惩罚
        - 武器读取铁律: 仅读取本次动作所使用武器的 ATK/MATK，未参与动作的武器绝对不计入；双手多武器动作每把独立分段结算
        - 应对窗口: 动作声明后、命中/效果判定前，目标可消耗本回合尚未使用的次要行动进行防御性应对；应对结算完成后继续本次主要行动，不得事后推翻已完成结果
     4. 检定规则:
        - 攻击检定: 1d100 + 属性修正 + 跨级修正 vs 目标防御DC (≥DC命中)
        - 豁免检定: DC = 50 + 施法者属性修正，目标 1d100 + 豁免修正 + 跨级修正 (≥DC豁免成功减半/免控)
        - 必中技能: 跳过命中检定直接进入伤害结算 (不免疫层级压制与减伤)
        - 极值响应: 96-100(奇迹/暴击，伤害×1.5且触发局部要害创伤) | 1-5(灾厄/大失败，行动落空且产生破绽)
     5. 多目标与范围规则:
        - 多目标消耗: {2目标: ×1.5, 3目标: ×2.0, 4目标: ×2.5, 5+目标: ×3.0}
        - 伤害分配: {主目标: 100%, 副目标: 70%, 范围爆炸AOE: 100%}
     6. 伤害流水线:
        - 物理构成: (固定值 + ATK) 或 (基础属性 × 倍率) + ATK
        - 魔法构成: (固定值 + MATK) × (1 + AP%) 或 (基础属性 × 倍率) × (1 + AP%) + MATK
        - 减伤结算: 单段最终物理 = 物理×(1-目标物理减伤%)；单段最终魔法 = 魔法×(1-目标魔法减伤%)；真实伤害无视一切常规防御与减伤率
        - 连击独立原则: 多段攻击每段独立 roll 命中并计算减伤，最终累加
        - 群体单位攻防: 群体数量不等于攻击段数，攻击方依实际接触面结算攻击段数；受击方依实际覆盖范围结算受击数量；群体受击总AOE伤害 = 单体伤害 × min(范围数, 当前存活数)
        - 次要行动衔接: 防御、打断、护援等应对只能在命中/效果判定前介入，并将修正并入本次主要行动；反击、机会攻击或反伤在原行动结算后调用同一伤害流水线，伤害只结算一次
     7. 承伤法则:
        - 扣血顺序: 优先扣减 THP，溢出部分扣减本体 HP；HP≤0 进入濒死/死亡
        - 群体减员: 新存活数 = 1 + ceil(新THP / HP_MAX) (THP归零后剩余1名本体承受HP扣减)
        - 单兵形态: 严格同生共死，无独立血条，承伤直扣本体 HP/EP；遭受重创判定形态大破
        - 资产载具双轨: 常规攻击仅扣减载具【完整度】，玩家受装甲物理保护不扣HP；完整度归零载具报废并触发逃生机制(第二条命)；常规低阶武器无法撼动大型装甲(战损0%)，重火力或同阶攻击单次战损扣减 1%~25%
     8. 驱散与状态:
        - 高品质状态绝对压制低品质状态；低品质驱散手段绝对无法解除高品质异常
     9. 伤损叙事对应:
        - 轻微[扣血1-10%]: 挠痒般的皮外伤 | 中等[11-49%]: 有效破甲，明显伤口 | 严重[50%+]: 重创创口，肢体失能，鲜血飞溅

  面板模板:
  <CombatResult>
    {主要行动}
    | 顺位: [X/总数] | 行动方: [行动者] | 目标: [承受方] | 消耗: [主要行动×1] $(若有消耗: , ${资源名} -[X]) |
    | 动作声明: [使用武器/释放技能名称] | 伤害类型: [物理 / 魔法 / 真实 / 混合] |
    | 命中推演: 1d100([骰值]) + ${属性}修正[±X] + 跨级修正[±Y] = [总值] vs DC[目标防御/豁免DC] ｜ [✅命中 / ❌未命中 / 💥奇迹暴击 / 💀大失败] |
    {伤害结算}
    | 物理构成: ATK[A] × (1 - 物理减伤[B%]) $(若有破甲: | 穿透[C%]) = [单段值] $(若多段: × [N]段) = [最终物理 E] |
    | 魔法构成: MATK[A] × (1+AP[B%]) × (1 - 魔法减伤[C%]) $(如有法穿: | 穿透[D%]) = [单段值] $(若多段: × [N]段) = [最终魔法 F] |
    | 真实/要害: 真实伤害[G] $(若触发暴击: | 要害倍率 ×1.5) = [最终额外 H] |
    | 总伤害: 💥 [总计点数] 点 |
    | 承伤更新: $(有THP: THP [旧] -> [新] |) HP [旧] -> [新] $(若为载具: | 完整度: [旧%] -> [新%]) |
    | 存活判定: [目标] HP [新] ｜ [健康 / 濒死 / 死亡 / 毁损] $(若为群体: | 存活数: [旧] -> [新]) |
    | 附加状态: [目标获得状态名(效果描述, 持续N回合) / 无] |
  </CombatResult>
  叙事指导: (具象化描写攻击的视觉效果、动作细节、打击感、受击者的反应及伤口)

# 第四阶段: 次要行动与移动 (核心循环)
  逻辑与规则:
     1. 资源归属: 次要行动属于使用它的单位；每单位每回合仅有1次，可在自己行动阶段主动使用，也可在敌方主要行动尚未结算前作为应对使用
     2. 主动类型: 快速道具使用 / 姿态切换(防御/掩护) / 装备切换 / 战术辅助
     3. 应对类型: 格挡 / 闪避 / 反击 / 打断 / 护援 / 替代承伤 / 装备或技能特效 / 机会攻击
     4. 应对时序: 敌方声明攻击或控制后，目标若本回合尚未使用次要行动且具备合法手段，可在命中/效果判定前使用；应对结算后继续敌方主要行动
     5. 应对限制: 次要行动已使用、未察觉攻击、无合法手段、应对窗口关闭、失能或死亡时，不生成应对面板；不得事后取消已完成结果
     6. 反击伤害: 反击、机会攻击或反伤沿用第三阶段伤害流水线，每次触发仅结算一次，不得重复触发
     7. 移动: 移动独立消耗 1[移动]，用于转移至掩体、拉开距离、突进或脱离战场
     8. 逃跑检定: 若声明脱离战场，敏捷修正对抗检定: 1d100+敏捷修正 vs 敌方敏捷修正 (成功则脱离)

  面板模板:
  <CombatResult>
    {次要行动与移动}
    | 顺位: [X/总数] | 行动方: [行动者] | 行动类型: [反应动作/战斗应对] | 消耗: [次要行动×1] |
    | 触发事件: [无/受到攻击/进入范围/友方受创/目标脱离等] | 目标: [单位] |
    | 动作声明: [使用道具/格挡/闪避/反击/打断/护援/切换装备/激活特效] |
    | 判定推演: $(若需判定) 1d100([骰值]) + ${属性}修正[±X] + 其他修正[±Y] = [判定结果] vs [目标DC/对抗结果] ｜ [✅成功 / ❌失败 / 💥奇迹 / 💀大失败] |
    | 应对效果: [对当前主要行动的修正 / 反击已触发并转入伤害流水线 / 其他效果 / 无] |
    | 移动位移: [无 / 转移至掩体后 / 拉开距离至XX米 / 突进至近战范围 / 脱离] |
    | 状态更新: [HP/THP/EP/位置/状态/次要行动剩余次数变化；主行动伤害由主要行动面板记录] |
  </CombatResult>
  叙事指导: (描写战术动作的具体表现，如喝药的动作、魔法咏唱、走位或防御姿态)

# 第五阶段: 战意判定 (条件触发)
  逻辑与规则:
    1. 触发: 仅当非玩家单位 HP 低于其战斗类型战意阈值时触发
    2. 阈值标准: 切磋(40%自动动摇) / 竞技(30%自动动摇) / 标准(30%需过检) / 死斗(10%需过检)
    3. 检定: 1d100 + 精神修正 vs 战意DC50 (失败触发: 溃逃/投降/求饶/战线崩溃/失能)

  面板模板:
  <CombatResult>
    {战意判定}
    | 触发单位: [角色/群体名] | 当前HP: [当前/最大] (低于阈值 [X%]) |
    | 判定类型: [自动触发 / 精神豁免检定] ｜ 1d100([骰值]) + 精神修正[±X] = [总值] vs DC50 |
    | 结果: [战意动摇 / 心理崩溃 / 顽抗坚守] -> 执行行为: [溃逃 / 弃械投降 / 丧失战意] |
  </CombatResult>
  叙事指导: (仅当触发时描写。白描敌方防线瓦解、丢弃武器或狼狈溃退的实际动作)

# 第六阶段: 战斗结算 / 回合收尾
  逻辑与规则:
    1. 战斗未结束时: 作为本大回合闭环终点，汇总全场单位剩余 HP/EP/THP、阵亡名单与下回合环境变化，结束本次回复。
    2. 战斗结束时 (全灭/投降/脱离):
        - 击杀统计与任务推进 (按生命层级写入变量，层级差≥2不计入击杀统计)
        - 战利品获取:
          - 击杀不自动掉落或获取战利品
          - 必须有明确来源，且先留在现场、尸体、容器等位置
          - 玩家主动【搜索/检查/拾取/搜刮】后才能获得
          - 未主动获取，不得进入变量、背包或结算
          - 无明确来源不生成战利品
          - 高品质战利品必须有明确剧情依据
        - 状态垃圾回收 (脱战强制清空全部临时战斗Buff，重伤按需转为世界状态)

  面板模板 (战斗中·回合收尾):
  <CombatResult>
    {回合收尾·战况更新}
    | 回合状态: 第 [N] 回合结束 | 本回合阵亡/离场: [单位X, 单位Y / 无] |
    | 下回合存活序列: [列出下回合可行动的全部单位] |
    | 战场环境变动: [火势蔓延 / 掩体破坏 / 距离缩短至XX / 无特殊变化] |
  </CombatResult>

  面板模板 (战斗结束·终局结算):
  <CombatResult>
    {战斗终局结算}
    | 战果: [战斗胜利 / 成功脱离 / 全灭溃败] | 战局总结: [简要物理结果] |
    | 击杀统计: ▸ [生命层级] × [击杀数] ｜ 任务推进: [击杀计数+1 / 目标达成] |
    | 可拾取物:
    |   🔹 [物品名称] (品质) ｜ 位置: [尸体/容器/地面/原存放处]

  </CombatResult>
  叙事指导: (描写战火渐熄、硝烟散去的场景，白描战利品散落与战场狼藉现状)
