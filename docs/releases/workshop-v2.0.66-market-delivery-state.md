# 创意工坊 v2.0.66 · 空间集市交易资产状态归一

## 玩家可见变更

- 空间集市 **装备、道具的商品详情不再显示“状态”**。装备的穿戴/仓库、道具的携带/战术栏/仓库只是持有者本地的装备位或存放位置，并非商品固有属性。
- **买入/成交领取新资产时**，装备的 `状态` 一律设为 `0`（未装备）；道具的 `状态` 一律设为 `0`（随身道具）；队友的 `在场` 一律设为 `true`。
- 支持市场普通购买、聚合目录购买、自由订单成交、交换成交等到账路径；玩家自己的存档仍由本地 MVU 安全写入并保留领取去重凭证。
- **撤销上架或订单退款退回自己的资产时**，保留原始状态（装备原来位于仓库继续为仓库、原本不在场的队友继续不在场），避免意外改变本人资产。
- 形态的“完好”等状态、人物的状态构筑不属于装备/道具放置位置，仍会照常显示。
- 道具堆叠先归一收到的状态，再寻找当前存档对应的堆叠位置，避免用卖家仓库状态错误匹配库存。

## 版本与测试

- CreativeWorkshop `2.0.66`
- Cloudflare Worker `0.13.23`（无修改）
- 回归涵盖：装备/道具状态隐藏、形态状态保留、买入后装备/道具/角色归一、堆叠、自由订单胜出及退款保留原始状态。
- 不修改玩家已有资产的状态、不变更交易数据库字段或后端业务。
