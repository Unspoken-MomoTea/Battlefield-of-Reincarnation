# 世界引擎 V2 审计与实施矩阵

审计日期：2026-09-10

参考对象：`Draw on/世界引擎`

目标：保留轮回战场现有 MVU、事件生命周期、场外人物投影与结构化输出优势，吸收参考实现的工作流式 Prompt 设计和 UI 信息层级；优先减少 AI 不需要知道的程序细节与重复结构说明。

## 审计原则

- 模型负责业务判断；Schema 负责结构；validator / normalizer / lifecycle 负责程序约束与存储维护。
- 同一规则只保留一个主来源，避免 DEFAULT_PRESET、CORE_WORLD_RULES、protocol()、Schema 四处重复。
- P0 只做 Prompt 分层手术，不改变 MVU 字段、补丁编译、事件生命周期、UI 行为和旧格式兼容。
- 用户自定义 Prompt 不被内置模板升级覆盖；只自动升级首次安装或当前使用内置默认的配置。

## P0 变更边界

本轮只修改：

1. `DEFAULT_PRESET`：从规则说明书改为明确执行 Pipeline。
2. `CORE_WORLD_RULES`：只保留自定义 Prompt 也不可绕开的业务不变量。
3. `protocol()`：删除与 Canonical Schema 重复的字段清单，仅保留 Schema 无法表达的业务语义。
4. 内置默认 Prompt 文档版本 `8 -> 9`。

本轮明确不修改：MVU 字段、WorldResult Schema、编译器、normalizer、事件分类修复、生命周期回收、世界书投影、场外人物热投影、NPC 构筑审计、UI 与主题系统。

## P0 验收条件

- 内置默认 Prompt 明显缩短，且不再出现同一字段结构在 DEFAULT / CORE / protocol / Schema 四处定义。
- Canonical Schema 仍随请求发送；专属 API 仍按 `json_schema -> json_object -> plain` 降级。
- 宏观 3~5 节点、区间桥接、偏移判定、时间容量、信息不对称、活跃异端、探索/势力业务语义仍存在。
- 主神任务、晋升试炼、任务状态、副本成就仍不由世界引擎读取/更新/驱动。
- 用户自定义 Prompt 文档不会因 v9 自动被覆盖。
- 不改变现有存档数据结构与 UI。
