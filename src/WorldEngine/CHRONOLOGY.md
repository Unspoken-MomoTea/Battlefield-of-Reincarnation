# 世界推进：原著剧情与时间轴约束

## 定位

世界推进以作品剧情为主轴。原著、权威世界书与数据库描述的是**未被玩家或世界真实改变时的默认未来**，不是不可改变的剧本。

- 当前事实与因果偏移不足以改变主线时，优先延续作品本来会发生的故事，而不是用随机新危机替代原著。
- 玩家、异端或世界自身已经造成主线级真实改变时，只重构真正受影响的节点；未受影响的原著节点继续保留。
- 原著有惯性，但没有“命运修正力”；不得为了回归原著强行制造等价死亡、替代事故、无因复活或补偿事件。

## 时间证据分级

1. **已发生事实**：最高优先级，不能被原著常识覆盖。
2. **明确到日的权威锚点**：硬校验。节点仍成立且没有明确因果偏移时，必须沿用该日期。
3. **月份、季节、时段、大致间隔**：软约束，保持原有精度并保守留白。
4. **事件顺序、条件剧情、原著趋势**：软约束，用于保持故事方向和因果顺序，不强造具体日期。
5. **模型已有作品知识**：没有更高优先级资料时用于维持主线惯性；不确定处宁可留白。

程序硬拒绝集中在“明确到日的宏观节点无因改期”。月份、时段、顺序、条件和趋势不会仅因合理估计差异触发整轮重试。

## 已确认偏移

明确日期并非绝对不可改变。当已经发生的剧情足以改变某个原著节点的日期、成立条件或是否发生，并且 `因果.偏移记录` 明确关联该节点时，可以提前、延后、取消、重构该节点，或重排真正受影响的后继节点。

偏移只影响存在因果关系的部分：不能因为一处偏移就丢弃整条原著时间线，也不能因为原著存在就把已经发生的改变强行修回去。

## 推演顺序

每轮先判断：如果 `<user>` 从现在开始不再干预，按照当前已确认现实，原著/权威剧情接下来最自然会发生什么？

随后按以下顺序组织世界推演：

`当前现实 → 默认原著走向 → 已确认因果偏移 → 下一宏观边界 → 当前/近期事件 → 地区与势力现场 → 人物行动 → 探索/传播/资产等辅助模拟`

人物、势力和地区仍自主运行，但应服务于“这个作品正在发生的故事”，而不是逐轮用随机世界事件淹没主轴。

## 与其它约束的关系

原著自由度不会取消世界活动、当前事件、探索粒度、人物认知、任务边界、资产去重、状态完整性等既有规则。这些约束用于防止数据冲突或模型偷懒，与原著是否可偏移是两个不同问题。

## 回归

`tests/world-engine-chronology-guard.cjs` 固定覆盖：明确到日的权威节点在无因果偏移时不得擅自改期；存在明确、关联且足以使原成立条件失效的主线级偏移时，只允许重构受影响节点，不要求强行回归原日期。
