# 创意工坊 v2.0.60：空间集市正式开放

## 版本
- 客户端：2.0.60
- Worker：0.13.22
- 原因：v2.0.59 已完成发布与数据安全修复，但正式通道的市场路由与前端入口仍被测试服专用开关隐藏。因此必须补发 v2.0.60 才能真正让正式用户访问集市。

## 更新简介

- **空间集市正式开放**：创意工坊的正式版本显示空间集市入口，并启用正式 Worker 的商品目录、自由订单与玩家交易接口。
- **WoW 风格分页**：公开商品、玩家自由订单及管理员市场列表每页最多展示 50 项，仅在翻页时向服务器请求后续数据。
- **自由订单统一**：将求购和交换整合为可描述需求、提供装备／道具／技能／血统／形态／角色与空间币的自由订单；不再开放旧式求购／交换撮合，新旧托管返还仍可在原存档领取。
- **资产保护**：撤销、退款、报价与下架操作的安全检查加强；冻结账户仍可撤回托管资产，断网情况下保留待核对凭证而不是错误自动退款。
- **记录清理与性能**：缩短已完成记录保留期、控制存档 MVU 已确认收据上限、回收过期零余额钱包；系统凭证无变化时不重复更新 D1。

## 发布检验
- 回归测试必须覆盖 `CLIENT_UPDATE_CHANNEL='stable'` 与 `'testing'`。
- 正式部署的 smoke test 额外检查 `/api/market/catalog` 与 `/api/market/deals` 均返回 200 和有效分页结构，不允许正式 Worker 在线但市场路由被隐藏。
- 世界推进、状态栏、辅助计算的独立正式版本保持不变。
