# 创意工坊 2.0.64 · 空间集市分类和刷新修复

## 用户可见修复
- **全部商品 → 分类 → 全部商品**：修正分类切换导致商品短暂消失或不正确显示的问题。
- 切换装备、道具、技能、血统、形态、角色等分类时，清除上一分类遗留的子类型、品质、搜索词及价格区间过滤，保证展示当前分类的完整商品。
- 多次快速切换分类时，旧请求返回不会覆盖最新分类，避免空页或错页。
- 顶部「刷新」真正刷新空间集市当前页面：
  - 浏览：清理当前商品列表、价格详情和分页缓存并重新拉取；
  - 订单：重新读取当前订单列表和报价详情；
  - 我的拍卖：清理个人缓存并读取最新拍卖与待领取内容；
  - 出售：重新读取当前存档资产和可售列表。
- 刷新成功提示与当前打开的页面一致。
- 保留服务器每页 50 项的分页机制和仅当前页加载策略，避免额外反复扫描所有商品。

## 技术与验证
- 视图级 `catalogLoadSerial` 避免老分类请求晚到时覆盖新 UI。
- 绑定 `currentBrowsePage`，在子类型选项刷新时保留正确分页结果。
- 顶部刷新分发到当前 `marketMode`，不再只能更新浏览区。
- UI 回归验证分类切换、历史筛选清理、快速请求乱序以及订单/拍卖/商品按钮刷新。
- Client: 2.0.64。Worker API 未改动，仍为 0.13.23。
