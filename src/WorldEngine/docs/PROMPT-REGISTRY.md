# 世界推进 Prompt Registry

## 原则

凡是会作为 AI 指令发送的静态文本，都必须登记到 `WorldPromptRegistry`，并在“提示词预设”页面可见、可编辑、可随预设保存/导入/导出。

每项至少记录：

- key
- 标题
- 来源
- 分类
- 发送条件
- 默认文本
- 当前文本
- 是否可编辑

## 当前覆盖范围

### 主世界推进

- 执行流程（分段提示词）
- 核心边界
- 宏观骨架
- 世界自救
- NPC 构筑审计
- WorldResult 输出协议

### 运行模块

- 任务只读
- 原著 / 数据库时间轴
- 分级维护
- 探索台账
- 因果与事实时间
- 世界时间
- 传闻常驻层
- 传闻刷新节流
- 传播来源边界
- 世界活动交付

### 辅助 AI

- 长期历史压缩

### 纠错重试

- 已有接受结果 + 补充清单
- 已有接受结果、无补充清单
- 首次纠错 / 无接受结果

## Schema

JSON Schema、变量白名单、引用校验、时间比较、删除策略等程序契约不是提示词，保持代码级固定，不放进可编辑 Prompt Registry。

## 新增 Prompt 的规则

新增任何实际 AI 指令时，必须同时：

1. 登记 Prompt Registry。
2. 指定发送条件。
3. 提示词预设页可编辑。
4. 预设保存/导入/导出可持久化。
5. 回归测试证明修改值会进入真实请求。
