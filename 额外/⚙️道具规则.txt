<道具生成规则>
# 核心定义: 所有非穿戴式物资（消耗品/材料/配方/秘籍/....）统归于【道具】分类，禁止将穿戴装备写入道具。

# 道具生成格式
  [道具名称]: (规范化命名)
    品质: F / E / D / C / B / A / S / SS / SSS
    类型: 消耗品 / 材料 / 配方 / 秘籍 / 弹药 / 纪念物 / 特殊
    标签: [来源标签, 核心功能, 可选生产特性...]
    效果:
      [效果名]: [明确量化效果]
    描述: [叙事背景与风味描述]
    状态: 0 (0:随身道具 | 1:战术栏 | 2:空间仓库)

# 专属类型字段
  配方/图纸类 (类型: 配方):
    - 效果必须明确写出: "需求工坊: [无/药炉/熔炉等] | 投入材料: [主材A(品质)×数量 + 辅材B(品质)×数量] | 产出物: [成品名称(品质)]"

  秘籍/心得类 (类型: 秘籍):
    - 效果必须明确写出: "研读消耗: [时间/EP] | 研读要求: [五维或前置技能] | 研读产出: 研读成功必定掌握技能【技能名】或成长状态【状态名】"
</道具生成规则>
