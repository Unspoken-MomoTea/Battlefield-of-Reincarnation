<生产制作协议>
生产制作:
  核心指令: 仅当{{user}}输入涉及明确制作行为时激活
  判定底层: 所有未另行规定的检定规则均直接继承《行为判定》
  专用规则: 本协议仅补充制作分类、工坊、材料、产出与制作专属结果
  面板规则: 生产行为使用<CraftResult>作为专用结算面板，不额外重复输出普通<CheckResult>

  制作判定继承:
    - 制作行为如符合《行为判定》的优势/劣势条件，直接沿用对应2d100取高/低规则
    - 材料品质缺陷、工坊条件等制作专属修正仅作为最终DC修正；通用环境修正沿用《行为判定》，不得重复计算

# 生产品质消耗(EP):
  半成品/成品/重铸(按品质):
    F: 10-30 | E: 30-80 | D: 80-200 | C: 200-500 | B: 500-1200 | A: 1200-3000 | S: 3000-8000 | SS: 8000-20000 | SSS: 20000+
  注: 消耗为生产单件的EP总值，批量制作时按实际产出数量计算总消耗

# 第一阶段: 生产准备
  逻辑与规则:
    1. 制作分类与配方限制:
       - 半成品制作 (材料 → 中间组件): 无需图纸，产物无独立用途，需检定。示例: 金属锭→金属板
       - 成品制作 (材料/半成品 → 最终品): 必须有图纸/配方，需检定。若半成品已可独立使用，亦按成品处理
       - 造物重铸 (成品 + 材料 → 调整属性): 须工坊，仅限单件，重铸品质不得高于投入材料的最低品质
    2. 行业属性:
       锻造(力量)-金属/重中甲/机械 | 炼金(精神)-药剂/神秘侧道具/爆炸物 | 烹饪(体质)-恢复/增益食物 | 裁缝(敏捷)-布皮甲/首饰/时装 | 附魔(精神)-铭文/刻印
    3. 品质要求 (仅半成品/成品/重铸):
       - 必须至少有两种同品质投入物才能产出对应品质，否则产物品质降一级，不含图纸制作
    4. 资源与材料限制:
       - EP不足直接终止；散装材料不得自行拆分为任意"材料份"
       - 成品常规投入(无配方明确时): 主材×1 + 辅材(同品质)×1 + 调和物(非必需)×1

# 第二阶段: 制作检定
  逻辑与规则:
    1. 检定流程:
       - 基础DC: 按《行为判定》的品质DC表读取 (F:40, E:50, D:75, C:100, B:130, A:160, S:190, SS:230, SSS:280)
       - 材料附加DC: F(+0) | E(+5) | D(+10) | C(+20) | B(+30) | A(+40) | S(+50) | SS(+70) | SSS(+100)
       - 最终DC: 基础DC + 材料/半成品DC累加 - 专属DC减免 (遵循互斥：已在此扣减的加成，检定公式中不得重复累加)
       - 检定公式: d100 + 关联属性修正 + 检定加成 (遵循互斥：已在DC构成中作为减免扣除的项，此处不得重复累加) vs 最终DC
       - 评级:
         - 💥大成功 (骰值96-100 或 结果≥DC+50): 完美产出
         - ✅制作成功 (结果≥DC): 正常产出
         - ⚠️制作失败 (结果<DC 且 骰值>5): 未完成，损耗50%投入材料
         - 💀大失败 (骰值1-5 或 结果≤DC-50): 100%投入材料损毁，并承受轻微物理/反噬伤害
    2. 资源消耗: 检定后扣除对应EP(按《生产品质消耗》表读取)

  面板模板:
  <CraftResult>
    {制作检定}
    | 制作目标: [物品名] (品质: [F~SSS]) | 制作类型: [半成品 / 成品 / 造物重铸] | 数量: [N] |
    | 行业: [锻造/炼金(附魔)/烹饪/裁缝] | 核心属性: [力量/精神/体质/敏捷] |
    | DC构成: 基础DC [X] + [材料/半成品A]DC[+Y] + [材料/半成品B]DC[+Y] ... - [物品/技能A]DC[-Z] - [物品/技能B]DC[-Z] ... = [最终DC] |
    | 制作检定: d100([骰值]) + 属性修正[±X] + 技能/特性加成[±Y] = [总值] vs DC [最终DC] |
    | 判定评级: [💥大成功 / ✅制作成功 / ⚠️制作失败 / 💀大失败] |
    | 资源与时间实扣: EP -[X] | 消耗时间: [实际经过时间] |
  </CraftResult>
  叙事指导: (白描淬火瞬间、药液凝固、刻画符文时的光华流动与张力)

# 第三阶段: 生产结算
  逻辑与规则:
    1. 结算规则(能独立使用的部件按成品):
       - 投入物损耗: 大失败100%损毁 / 失败50%损耗 / 成功或奇迹响应正常消耗
       - 奇迹响应增益: 单件获得额外专属词条，或使原定效果增强；重铸属性达到配方允许的预定上限
       - 产出物品质: 由投入物品质决定，至少两种同品质投入物才可产出对应品质，否则降一级
       - 成品数值(仅成品): 成功取该品质数值区间的40%-60% | 奇迹响应取90%以上 | 参照<品质效果数值规则>
    2. 产出物直接生成规范化面板，供正文展示并写入背包
